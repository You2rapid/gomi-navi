# 毎年4月の更新のしかた（v3：周南市・下松市・光市）

ごみの収集日は、年度ごと（4月〜翌年3月）に市が新しいカレンダーを出します。
このアプリで毎年変わるのは **収集日と祝日だけ** です。どちらも `v3/data/` フォルダの別ファイルに分けてあります。

| ファイル | 中身 |
| --- | --- |
| `v3/data/holidays.js` | 祝日・休日と年末年始（内閣府の「国民の祝日」CSVから作る） |
| `v3/data/calendar_shunan.js` | 周南市の収集日と、町名 → 日程の一覧 |
| `v3/data/calendar_kudamatsu.js` | 下松市（西地区・東地区）の収集日 |
| `v3/data/calendar_hikari.js` | 光市（7地区）の収集日 |

どれも道具（スクリプト）で自動で作るファイルです。手で書きかえないでください。
品目検索の品目（分別のしかた）は `index.html` の中にあり、市が分別の冊子を改定したときだけ直します。

## 手順（例：令和9年度＝2027年度に切り替える）

市のサイトに新しいカレンダーが出てから（例年2〜3月ごろ）、`gomi` フォルダで次を実行します。
必要なもの：Python と `pip install pymupdf pykakasi`

1. **元データをダウンロードする**
   ```
   python v3/tools/download_sources.py 2027
   ```
   市のサイトから新しいカレンダーのPDFなどを探して、`元データ/2027年度/` に保存します。
   「見つからなかったもの」が出たら、まだ新しい年度の分が出ていないか、市のページのつくりが変わっています（下の「うまくいかないとき」）。

2. **アプリのデータを作り直す**
   ```
   python v3/tools/update_year.py 2027
   ```
   PDFを読み取って `v3/data/` と `v3/geo/towns.json` を作り直します。
   読めないところがあると途中で止まり、`v3/data/` は前のまま残ります。

3. **確かめる**
   アプリをブラウザで開き、各市のいくつかの地区で、カレンダーが市の配布物と合っているか見くらべます。
   4月より前に確かめるときは、アドレスの最後に `?date=2027-04-01` を付けると、その日として表示されます。
   - 光市：大和地区だけ出す時刻が朝7時30分まで（`tools/extract_hikari.py` の `CUT`）。変わっていないか
   - 周南市：山間部（徳山山間・和田山間）の「※」の注記（`tools/extract_calendar.py` の `MOUNTAIN_OVERRIDES`）。新しいカレンダーの注記を見て足す
   - 地区の分け方・住所が変わっていないか（光市は `tools/extract_hikari.py` の `AREAS`、下松市は `tools/extract_kudamatsu.py` の地区の説明）

4. **公開する**：GitHub Desktop で Commit → **Push origin**

## うまくいかないとき

- **download_sources.py で見つからない**：下のページをブラウザで開いて、PDFを手で保存し、
  `元データ/2027年度/<市>/` に決まった名前で置きます（名前は `tools/update_year.py` の `CITIES` に書いてあります）。
  そのあと `python v3/tools/update_year.py 2027 --check` で、そろっているか確かめられます。
- **update_year.py が「読み取れませんでした」で止まる**：市がカレンダーの形（色・配置）を変えた可能性があります。
  Claude に「令和9年度のカレンダーが読めない」と頼んで、`tools/extract_*.py` を直してもらってください。

## 元データ フォルダ（このパソコンだけにある）

`gomi/元データ/` には、市からダウンロードしたPDFなどの元の資料を置いています。
市の資料なので GitHub には上げません（`.gitignore` で除外）。パソコンを買いかえるときは、このフォルダもコピーしてください。

```
元データ/
  2026年度/        ← 年度ごとのカレンダー（周南市・下松市・光市・祝日）
  2027年度/        ← 来年、download_sources.py で増える
  分別の冊子/      ← 品目検索の元にした冊子（改定されたときだけ差しかえる）
  地図/            ← 「今いる場所から探す」の町の境目（e-Stat 国勢調査の境界データ。5年ごと）と、下松市の地区の地図
```

## たまにしか変わらないもの

- **分別の冊子**（品目検索）：周南市は `tools/extract_items.py`（v1）、光市は `tools/hikari_items/` に作り方の記録があります。
  下松市は冊子の例を手で入れています。改定されたら Claude に頼んでください。
- **町の境目の地図**：国勢調査（5年ごと）の新しい境界データが出たら、`元データ/地図/` の KML を差しかえて
  `python v3/tools/build_geo.py 元データ/地図 v3/geo/towns.json` を実行します。
