- 使った資料：市のサイト「岩国市ごみ収集カレンダー［令和8（2026）年4月～令和9（2027）年3月］」
  https://www.city.iwakuni.lg.jp/soshiki/23/113972.html
  - 地域（岩国・由宇・周東・玖珂・錦・美川・美和・本郷）ごとのページに、地区（町名・字・自治会名）ごとの PDF がある（219件）。

- PDF のつくり：1冊28ページの冊子。表紙に **日程の記号**（A1・C2・F・I3・A4-1 など）、2〜7ページがカレンダー（1ページに2か月）、
  9〜27ページが「家庭ごみの分け方・出し方マニュアル」。
  - 同じ日程の記号の PDF は、収集日も同じ（219件すべて読んで確かめた。日程は36）。
  - カレンダーの札は文字なので、そのまま読める（焼却ごみ・プラスチック・びん・かん・資源品・金属 破砕・陶磁器 ガラス・ペットボトル・全品目・粗大ごみ 戸別有料収集日・粗大ごみ 申込締切日）。
  - **行波（荒瀬谷）（B4-1）だけ**、カレンダーがスキャンした画像で、日付や曜日が文字でない。絵の中の黒い罫線からマスの位置を出して、上にのっている札の文字を読む（`calendar.py` の `image_grid`）。
  - 日程の記号の「Ⅰ」（ローマ数字）は、ふつうの「I」にした（I1・I2・I3）。
  - 年末年始・祝日の休みは、PDF のカレンダーにそのまま出ている（札がない日）ので、別に足すことはない。
- 読み方（`calendar.py`）：
  - `download`：「ごみ・リサイクル」のページ → その年度のカレンダーのページ → 地域のページ → 地区の PDF をたどって保存。
    地区の名前は地域のページの表から作り、`地区一覧.json` に書く（表の「南岩国町」「北」「下久原」「広瀬」などのまとめの見出しは、地区名の前につける。例：`南岩国町一丁目1～23番`、`神東（大畑）`）。
  - `make_calendar`：PDF をすべて読み、日程（記号）ごとの収集日と、地区 → 日程の対応を作る。読めない札・そろわない日付・同じ記号なのに収集日がちがう PDF があると止まる。
- 置き場所：`元データ/35_山口県/35208_岩国市/2026年度/`
  - `地区一覧.json`（地区名と PDF）、`地域ページ/*.html`、`地区のカレンダー/<番号>.pdf`（219件・**約1.5GB**。1冊が約7MBあるため）
- **毎年やること**（ふつう3月ごろ。令和8年度のページは 2026-03-06 に出ていた）：
