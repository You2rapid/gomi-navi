## 収集日（毎年）

ダウンロード元：https://www.city.shunan.lg.jp/soshiki/19/ にある「令和○年度ごみ収集カレンダー（徳山・新南陽・熊毛・鹿野）」のページ。

| 元データでの名前 | 中身 |
| --- | --- |
| `A.pdf`〜`H.pdf` | A〜H日程のカレンダー（徳山のページ） |
| `otsushima.pdf`・`tokuyama_sankan.pdf` | 大津島・徳山山間（徳山のページ） |
| `wada_sankan.pdf` | 和田山間（新南陽のページ） |
| `tokuyama.html`・`shinnanyo.html`・`kumage.html`・`kano.html` | 各ページそのもの（町名 → 日程の表が載っている） |

注意：
- 山間部（徳山山間・和田山間）は1マスに区分が小さく描かれていて色で読めないため、`calendar.py` の `MOUNTAIN_RULES`（曜日のきまり）で区分を決めている。
  カレンダーの「※」の注記で決まる日は `MOUNTAIN_OVERRIDES` に手で書く。**毎年、新しいカレンダーの注記を見て足す**。
- 月のマスの位置（`BLOCKS`）はPDFの配置に合わせてある。配置が変わると読み取りが止まる。

## 品目（オープンデータ）

山口県オープンデータカタログサイト「【周南市】ゴミの分別方法一覧」（CC BY 4.0）の CSV から `opendata.py` で作る。
`python gomiappV3.1/tools/update_opendata.py 35215`（取ってきて `元データ/35_山口県/35215_周南市/オープンデータ/` に保存し、items.js を作る）。
オープンデータに無いが、よく探される言葉（生ごみ・雑がみ）は `opendata.py` の `EXTRA` で足している。
冊子「家庭ごみの分別方法」（`分別の冊子/`）から読み取る前の道具（`extract_items.py`・`make_items.py`）も残している。オープンデータが古くなったときに使う。
