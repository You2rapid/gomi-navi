## 収集日

- 使った資料：市のサイト「令和８年度家庭ごみ分別収集カレンダー」
  https://www.city.hofu.yamaguchi.jp/soshiki/16/calendar-.html
  - ページの下に、地域（牟礼・松崎・佐波・勝間・華浦・新田・野島・向島・中関・華城・西浦・右田・玉祖・富海・小野・大道）ごとの表がある。
    表の1行が「自治会名の並び → カレンダーの PDF」。
  - PDF は2種類。**全収集日掲載版**（燃やせるごみ・プラスチック製容器包装・資源ごみ・危険ごみ・燃やせないごみ）と、
    **自主搬入等対応版**（燃やせるごみ・プラスチック製容器包装だけ。資源ごみなどを自治会で市へ運ぶ地区）。富海・小野は全収集日掲載版だけ。
  - 収集日のオープンデータはない（山口県オープンデータカタログの防府市のデータセット30件に、ごみ収集カレンダーはない。2026-11-24 に確認）。
- PDF のつくり：2ページ（1ページ目が4〜9月、2ページ目が10〜3月）。ページは横向きに置いて回してある。
  - マスに日付の数字と、札の文字（可燃・プラ・資源 危険・不燃）が文字で入っているので、それを読む（`calendar.py`）。
  - 「資源 危険」の札は、資源ごみと危険ごみが同じ日。アプリでは区分「資源」と「危険」の2つをその日に入れた。
  - 「24/31」のように2つの日が1マスのところは、札は両方の日にかかる（同じ曜日）。
    **勝間（全収集日掲載版）の 8月だけ**、マスを2つに分けて「24（可燃・不燃）/31」と書いてある。31日は札がなく背景の色（燃やせるごみのピンク）だけなので、色で読む（`bg_cats`）。
  - 3月の最後の行の灰色の「4/1」「4/2」（次の年度の日）は入れない。
  - 年末年始・祝休日の休みは、PDF のカレンダーにそのまま出ている（札がない日）ので、別に足すことはない。
    祝日のうち収集する日（令和8年度は 4/29・7/20・8/11・9/21・9/22・9/23・10/12）も、PDF に札がある。
  - 祝日で休みになった燃やせないごみの日を別の日に移しているところ（例：勝間 11/23（月・祝）→ 11/26（木））は、アプリで「振替日」と出る。
- 日程（カレンダー）の名前：PDF の名前から作った（30）。全収集日掲載版は「牟礼小校区」「松崎」…、自主搬入等対応版は「牟礼小校区・自主搬入」「松崎・自主搬入」…。
  - `make_calendar` は、自主搬入等対応版の燃やせるごみ・プラの日が、同じ地域の全収集日掲載版と同じかを確かめる（ちがえば止まる）。
- 地区：表の自治会名（251）。地域を `regions` にした。
  - 中関の「田島宿舎」の行は、リンクの名前が「中関」で、中身は中関の自主搬入等対応版（144789.pdf）と同じファイルなので、「中関・自主搬入」にした。
  - PDF のない3つ（松崎の **新天地**・**野島地域自治会連合会**・小野の **奥畑**。表に「排出日等については、自治会に確認してください。」）は入れていない（「出し方」タブに書いた）。
  - 自治会名のよみは、自動でつけている（`kana.yomi`）。地元の読み方とちがうものがある（例：江泊＝こうはく）。検索だけに使う。
- 読み方（`calendar.py`）：
  - `download`：クリーンセンターのページ（/soshiki/16/）から「令和○年度家庭ごみ分別収集カレンダー」を探し、そのページと表の PDF を保存する。
  - `make_calendar`：ページの表と PDF をすべて読む。月の見出し・日付がそろわない、知らない札の文字がある、などのときは止まる。
- 置き場所：`元データ/35_山口県/35206_防府市/2026年度/`
  - `カレンダーのページ.html`、`カレンダー/<番号>.pdf`（31件・約82MB）
