## 収集日

- 使った資料：市のサイト「ごみ収集日カレンダー」の、地区ごとのページ（24地区）
  https://www.city.ube.yamaguchi.jp/kurashi/gomi/dashikata/1001977/1014196/1001979/index.html
  - 地区のページには、毎週のごみ（燃やせるごみ：月・水・金、プラスチック製容器包装：火か木）と、
    月1回の「燃やせないごみの日」「古紙の日」の日付の表（「令和8年」「令和9年」の1〜12月）が文字で載っている。
  - 市の日程表は **暦年（1〜12月）**。アプリの年度（4月〜3月）は、令和8年の表の4〜12月と、令和9年の表の1〜3月から作る。
  - 年末年始：市のページ「年末年始のごみ収集日程・施設等の開場状況（令和8年12月から令和9年1月）」
    https://www.city.ube.yamaguchi.jp/kurashi/gomi/dashikata/1001977/1014196/1001980.html
    - 燃やせるごみ：12/30（水）まで。年始は東岐波・西岐波・常盤・恩田・岬・見初・神原・琴芝・上宇部・川上・船木が 1/5（火・臨時収集）、ほかの13地区が 1/4（月）。1/6 からいつもどおり。
    - プラスチック製容器包装：木曜日の地区は 12/24 まで・1/7 から、火曜日の地区は 12/29 まで・1/12 から。
    - これを `calendar.py` の `YEAR_END` に書いた（1/5 の臨時収集は「振替」として出る）。
  - 祝日：毎週のごみは祝日も収集する（市の日程表・地区のページに祝日の休みは書いていない。年末年始だけ変わる）。
  - 収集日のオープンデータ：山口県オープンデータカタログ「【宇部市】ごみ収集」の「各地区のごみ収集日」（CSV、2026年1〜12月）がある。
    暦年なので2027年1〜3月がない。`calendar.py` は、2026年の月を CSV と見くらべ、ちがえば止める（今回は 432日・24地区すべて合っていた）。
- 区分の分け方：市の日程表の「燃やせないごみの日」には、びん・缶／ペットボトル／燃やせないごみ／月1回収集の燃やせるごみ／危険ごみの5つ、
  「古紙の日」には古紙（新聞・雑誌・雑がみ・段ボール）／紙製容器包装の2つを出す。品目検索の区分と同じにして、「次に出せる日」が出るように、
  その日にこの5つ（2つ）の区分を入れた。厚南は燃やせないごみの日と古紙の日が同じ日なので、1日に7つの札が出る。
- 地区：24（市の地区のページの数と同じ）。地区の名前は市のページのとおり（「東岐波地区」の「地区」は取った）。
- 置き場所：`元データ/35_山口県/35202_宇部市/2026年度/`
  - `ごみ収集日カレンダー.html`（一覧のページ）、`地区のページ/<地区>.html`（24件）、`年末年始.html`
  - `家庭ごみ収集日程表_令和8年.pdf`・`家庭ごみ収集日程表_令和9年.pdf`（全地区分の日程表。見くらべる用）
- **毎年やること**：
  1. 11月ごろ、市が「年末年始のごみ収集日程」と次の年の日程表（地区のページの表）を出す（令和9年の表は 2026-11-01 にはあった）。
     `calendar.py` の `YEAR_END` に、その年度の年末年始を足す（足していない年度は 12/31〜1/3 を休みとして作り、「仮」の注意が出る）。
  2. 次の年度（例：2027年度）は、令和9年と令和10年の表がいるので、**令和10年の表が出たあと（2027年11月ごろ）** に作れる。
     それまでは 2027年4〜12月だけは作れない（`make_calendar` が「令和10年の表がありません」で止まる）。
