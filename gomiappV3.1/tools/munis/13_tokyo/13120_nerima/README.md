  - 「地域別収集曜日一覧」 https://www.city.nerima.tokyo.jp/kurashi/gomi/wakekata/ichiran/index.html
    の7ページ（あ行 `a_gyochiiki.html`・か行 `ka_`・さ行 `sa_`・た行 `ta_`・な行 `na_`・は行 `ha_`・ま行や行 `maya_`）。表の見出しは「○行の地域（令和8年度）」
  - 表の行ごとの「カレンダー（PDF）」（令和8年4月〜9年3月、A4 2ページ、**文字入り**）。101冊、ぜんぶで約5MB
- 区分（5つ）：可燃ごみ（週2回）・不燃ごみ（月2回、第1・3か第2・4の○曜）・プラスチックと古紙（週1回、同じ日。カレンダーの札は「プ 紙」）・飲食用びん・缶（週1回）・ペットボトル（週1回。びん・缶と同じ日の地域が多いが、ちがう地域もある）
- **収集日はカレンダーの PDF の日付をそのまま使う**（`calendar.py` の `read_pdf`）。祝日も収集する。年末年始の休みも PDF に入っている（令和8年度：12月31日〜1月2日）。
  - 読み方：1ページに6か月。月の見出し（「2026」と月の数字）・曜日の見出し（日〜土）の位置から列を決め、日付の数字の下の札の字（可・不・プ・紙・び・缶・ペ）を、同じ列のすぐ上の日付につける。ページの下の凡例は読まない。
  - 日付の数字が曜日の列と合わないとき、札の日付が決まらないとき、12か月そろわないときは止まる。
- **表の曜日とくらべる**：表の曜日で作った日と PDF の日をくらべ、PDF にだけある日があれば止まる（表とカレンダーの食いちがい）。表にあって PDF にない日は休みとして `読み取りの注意.txt` に書く。
  令和8年度は、101地域すべてで、ちがうのは **2026-12-31・2027-01-01・2027-01-02 だけ**（年末年始）だった。
- 地区：表の行のとおり **101**。名前は「町名＋丁目」（「全域」は町名だけ）。丁目でないもの（団地・宿舎）は「町名（…）」：
  「旭町（都営光が丘第一アパート）」「旭町（上記以外の地域）」「北町（2丁目練馬北町宿舎A~F棟）」「田柄（2丁目42番4~6号棟）」、光が丘は棟・番ごとに19。
  「上記以外の地域」には、説明に「都営光が丘第一アパート以外」と書いた。地区の説明には、カレンダーの問合せ先の清掃事務所も書いた。

- 置き場所：`元データ/13_東京都/13120_練馬区/2026年度/`（`曜日一覧_*.html`・`カレンダー/*.pdf`・`地域別収集曜日一覧.html`・`年末年始のお知らせ.html`）

## 今いる場所から探す

- e-Stat の町丁（202）を、地区名の町名と丁目でくらべる（`geo.py`）。丁目のない地区（全域・団地）は、その町のすべての町丁を候補にする。
  かっこの中の丁目（「光が丘（1丁目2番2号棟 2丁目9番）」→ 光が丘1丁目・2丁目）も候補にする。
- **201／202 町丁で地区が決まる**。決まらないのは光が丘四丁目だけ（光が丘公園。地域別収集曜日一覧にない）。
- 候補が2つ以上の町丁は10（光が丘・北町・田柄・旭町で、同じ丁目の中に収集日のちがう団地や宿舎がある）。使う人が候補から選ぶ。
