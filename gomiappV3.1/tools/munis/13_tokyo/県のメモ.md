# 東京都（13）県のメモ

県の係（エージェント）が、都で共通のことと、区市町村ごとの進み具合を書くメモです。
次の係が続きから作れるように、わかったことはここに書きます（手順書 `gomiappV3.1/tools/AGENT.md` の「0. 県ごとの進め方」）。

- 県のフォルダ：`gomiappV3.1/tools/munis/13_tokyo/`、データ：`gomiappV3.1/data/13_tokyo/`
- 元データ：`元データ/13_東京都/`
- 特別区（23区）は、それぞれ1つの自治体（コード 13101〜13123）。政令指定都市の区とはちがうので、区ごとに作る。

## 次の係へ

- いまの進み具合（2026-11-27）：世田谷区・練馬区・大田区・江戸川区・足立区・杉並区・板橋区・八王子市・江東区の9つが「できた」。**次は葛飾区（13122）**、そのあと町田市・品川区…。保留はまだない。
- 八王子市・江東区でわかったこと：
  - **八王子市（市の1つ目）**：町ごとの曜日の表はなく、**20の「収集地区」ごとの年度カレンダー PDF**（1か月1ページ、マスに区分の絵と名前の文字）だけ。マスの文字を位置で日付に結びつけて全日読む（`read_pdf`）。袋の絵の中の「可燃ごみ 専用」は「すぐ下に『専用』がある行」でのぞき、お知らせの囲みの大きい字（10.5pt 以上）はのぞく。「24/31」の斜めのマスは、マスの左上を基準に集めて、文字の数と前の2回の間かくでどちらの日かを決める。**隔週の組み合わせが年末年始で入れかわる**ので、曜日の決まりから作らない。地区は「町名一覧」の138行（番地・団地で分かれる町は e-Stat では分けられず、候補2つ）。品目は「分別辞典」PDF（表の文字、1121件）。**多摩の市は、カレンダー PDF をそのまま読む形が多いかもしれない**。
  - **江東区**：地区1〜12ごとに曜日で決まる。**収集日一覧 PDF・年末年始カレンダーが文字のない画像**だったので、拡大して読み、`DISTRICTS`・`YEAR_END` に書き写した（燃やさないごみは隔週で、4月の1回目の日から2週ごと。年末年始の臨時の日は `moved` に入れて「振替」と出す）。収集日のオープンデータ（2024-11）は**豊洲・塩浜の地区番号が古い**ので、地区は区の PDF を使い、曜日の見くらべだけに使う。オープンデータの「じゅうしょ」（読み）にもまちがいがある（新大橋＝しんきば など）。
  - **Bash のコマンドの中に `\1` を書くと、制御文字に化けることがある**（Python の正規表現の後方参照）。ファイルを直すときは Edit を使うか、後方参照を使わない書き方にする。
  - カレンダー PDF が大きい（八王子市は1枚 11〜15MB・20枚）と、`update_year.py` に2分ほどかかる。
  - ブラウザでのアプリの確認は、プレビューのページを開くのを許可されず、できなかった（スマホでの確認は人がやること）。
- 杉並区・板橋区でわかったこと：
  - 杉並区：曜日の CSV（`garbage.csv`）＋地域カレンダー PDF のマスの文字。**品目の50音順 PDF が画像だけ**だったので、Windows の OCR（`ocr.ps1`。光市と同じもの）で読んだ（`make_items.py`）。罫線で行を分け、読めないマスは切り出して読みなおし、それでも読めない品名・区分は画像を見て `NAME`・`CATFIX` に書いた。OCR の読みまちがいは `FIX`・`NOTEFIX`。**画像だけの PDF の品目は、この形をまねる**。
  - 板橋区：区のページの一覧表（HTML）＋地域カレンダー PDF 24枚の**マスの色の四角**（`get_drawings` の fill。緑・ピンク・水色）。「24/31」のように2つの日が1つのマスもある。**年末年始は11月に別の表（地域のまとまりごとの12月最終日・1月開始日）**が出るので、`YEAR_END[年度]["table"]` に書き写して全地区をくらべる。12/31 に可燃だけ収集する（`keep`）。
  - 板橋区の品目 PDF は、品名がまとめたセル・名前が右の列にはみ出す・出し方の列だけまとめたセル、があった。横線の長さ（x0・x1）で「品名の区切り」「行の区切り」「出し方の区切り」を見分ける（`hlines`）。
  - **品目のオープンデータが古いことが多い**：杉並区（a2.csv、令和7年4月）・板橋区（カタログ、令和6年4月のプラ分別より前）。区のページの今の年度の PDF とくらべて、新しいほうを使う（決まり A4 の「いちばん上」でも、古くて内容がちがうなら使わない。理由を README と license.json に書く）。
  - 町名の読みは pykakasi だと「○○町＝まち」「大谷口＝おおたにくち」などをまちがえる。郵便番号一覧の読みと全地区くらべて、ちがうものを `YOMI` に書く（板橋区は22）。
- 江戸川区・足立区でわかったこと（前の係）：
  - 江戸川区：曜日表の HTML（番地・建物で分かれる行あり）＋年末年始は曜日ごとの表なので、全曜日をくらべられる。ページの「西小松川」は正式な「西小松川町」に直した。
  - 足立区：令和8年4月からプラスチック分別。カレンダー PDF のマスはぼかし塗りで、色みの多数決で読む（`cell_cat`）。**年末年始（12/24〜1/10）は12月の広報で発表**なので、いまは `yearEnd.tentative` で「未定」。**12月に `YEAR_END[2026]` を書いて作り直す**。品目は「これは何ごみ？」PDF を位置で読む `make_items.py`（2行の品目名・分け方の行に注意）。
  - `geo.py` は江戸川区・足立区の形（地区名の「○丁目」で町丁を候補に）が、町ごとに曜日で決まる区ならそのまま使える。
- 地図（e-Stat の KML）は62区市町村ぶんそろっている（`元データ/13_東京都/<コード>_<名前>/地図/r2ka<コード>.kml`）。
- `build_geo.py` は必ず `13` を付けて動かす。`update_year.py 2026 <コード>` も中で `build_geo.py 13` を動かす（`data/holidays.js` も書き直すが、中身は同じで差分は出なかった）。
- 区で使った形（まねる元。杉並区・板橋区は上に書いた）：
  - **世田谷区**：曜日の CSV（区のページ）＋カレンダーの対象地区の番号。カレンダー PDF の色の札を読んで自動で見くらべる（`pdf_days`）。
  - **練馬区**：地域ごとの年度カレンダー PDF（文字の札「可・不・プ 紙・び 缶 ペ」）をそのまま読む（`read_pdf`）＋曜日の表とくらべる。
  - **大田区**：オープンデータの曜日（古い年度のシート）＋年末年始のお知らせの表（その年度の地区と、年末最終日・年始開始日）でくらべる。HTML の表の結合セル（rowspan）を広げる `table_rows` がある。
- 気をつけること：
  - 23区は「祝日も収集・年末年始だけ休み（12/31〜1/3 が多い）」。区のカレンダー・年末年始のページで、その年度の休みを必ず見る（`YEAR_END`）。
  - オープンデータが古い年度のまま（大田区の R07）のことがある。区のページの今の年度の資料とくらべて、分け方が変わったところ（大田区は大森北5丁目）を見つける。
  - 分別辞典が民間の「ごみサク」だけの区がある（大田区 0056）。写さずにリンクだけ置き、区のページの例を品目にする。
  - 練馬区は令和8年10月から製品プラスチックもプラスチックの日に変わった。ほかの区でも分別の変更（プラスチックの一括回収など）がないか、お知らせのページを見る。
