## 収集日

- 使った資料
  - 区のサイト「足立区で生活する外国人の方へ【ごみ収集スケジュール】」（2026-03-13 更新）の「地区別の収集曜日一覧」 https://www.city.adachi.tokyo.jp/seso/kurashi/sche.html
    … 98地区（町丁目）ごとの燃やすごみ・プラスチック・燃やさないごみ・資源の曜日（HTML の表）。翻訳用のページだが、令和8年度（プラスチック分別回収のあと）の曜日。
  - 区のサイト「令和８年度『資源とごみの収集カレンダー』」（2026-04-08 更新） https://www.city.adachi.tokyo.jp/seso/2026calender.html
    … 日程ごとのカレンダー PDF（12枚。`001.pdf`〜`012.pdf`・`002_1.pdf`）。上に地区の一覧、日付のマスの色が区分。`002.pdf` は「町丁別収集曜日一覧表」（画像だけ）。
- **足立区の収集日は、町丁目ごとに曜日で決まる**。燃やすごみ 週2回・プラスチック 週1回・燃やさないごみ 月2回（第1・3か第2・4の曜日）・資源 週1回。**祝日も収集する**。
  - **令和8年4月から区内全域でプラスチックの分別回収**が始まり、曜日が変わった。プラスチックはプラマークの容器包装と、すべてプラスチックでできた製品。
  - スプレー缶・カセットボンベは「資源」（缶のコンテナ）。
- 作り方（`calendar.py`）：
  - 曜日一覧の行を、そのまま地区にする（98地区・12日程）。
  - **12枚のカレンダー PDF を読んで、地区の一覧と日付のマスの色（プラ＝紫・資源＝緑・燃やす＝ピンク・燃やさない＝青）を、曜日から作った日と1日ずつくらべる**（合わなければ止まる）。マスはぼかしで塗られていて、とてもうすいところがあるので、マスのふちの何か所かの色みの多数決で読む（`cell_cat`）。12枚・98地区すべてで合った。
- **年末年始（12月24日〜1月10日）はまだ発表されていない**（カレンダーでは空いていて「12月の広報やホームページ等をご覧ください」）。推測で日を入れずに、その期間を「未定」（`yearEnd.tentative`）にした。アプリでは、その日に「未定」と出る。
- 置き場所：`元データ/13_東京都/13121_足立区/2026年度/`（`曜日一覧.html`・`カレンダー.html`・カレンダー PDF）
- **毎年やること**：
  - **12月（令和8年度はすぐ）**：区の広報・ホームページで年末年始の収集日が出たら、`calendar.py` の `YEAR_END[2026]` を `"tentative": False` にして、休みの期間と、その間に収集する日（日程ごと）を `"days"` に書き、`update_year.py` で作り直す。
  - 4月ごろ：新しい年度のカレンダーのページ（`seso/<年>calender.html`）が出たら、`download_sources.py` → `update_year.py`。
  ```
  python gomiappV3.1/tools/update_year.py 2026 13121
  python gomiappV3.1/tools/download_sources.py 2027 13121
  python gomiappV3.1/tools/update_year.py 2027 13121
  ```
