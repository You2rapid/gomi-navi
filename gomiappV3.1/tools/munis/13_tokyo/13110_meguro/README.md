  - 「地域別収集終了日・開始日」PDF（2026-11-06 作成）… 地域ごとに、資源・可燃・不燃の年末の最後の日と年始の最初の日、12/2 以降の水銀の回収日。
- **目黒区の収集日は、町名・丁目のまとまり（44地域）ごとに曜日で決まる**。燃やすごみ 週2回・資源（プラスチック・ペットボトル・びん・缶）週1回・燃やさないごみ 月2回（第1・第3 か 第2・第4 の曜日）・水銀を含む製品 月1回（燃やさないごみの2回のうち決まった1回）。**祝日も収集し、日曜日と年末年始（12/31〜1/3）は休み**。
- **古紙（新聞・雑誌・雑がみ・段ボール）は、区の収集ではなく町会などの集団回収**（曜日は番地ごとに町会で決まる。「古紙回収 曜日一覧」）。区のカレンダーにも入っていないので、アプリのカレンダーには入れず（決まり A1。地域を番地で分けない）、区分「古紙（集団回収）」の説明に「古紙回収 曜日一覧か集積所の看板で確かめる」と書いた。
- 作り方（`calendar.py`）：
  - **カレンダー PDF 44枚を全日読む**（`read_pdf`）。月の見出し（「2026年 4 月」）の下の曜日の行から列の幅を出し、日の数字の位置（行・列）と文字で日付を決める（見えない前の月・次の月の数字もあるので、位置から出した日付と数字が合うものだけ使う。「24/31」のように2つの日が1つのマスのときは下の段）。区分の文字は、となりのマスの文字とつながって読めることがあるので、`search_for` で文字の場所を探し、すぐ上の日の数字に結びつける。下の段の月の見出しの数字（「7 月」の 7）は日の数字に入れない。
  - 読んだ日を、**収集曜日一覧表の曜日の決まりと全日くらべる**（合わなければ止まる）。
  - 年末年始：カレンダーが空白の 12/27〜1/3 は、お知らせの休み（12/31〜1/3）の前の日（12/28〜12/30）を曜日どおりに入れ、**地域別収集終了日・開始日の表と全44地域・全区分くらべる**（水銀の日も）。お知らせがその年度のものでなければ（書いてある曜日が合わない）、12/27〜1/3 を「未定」にする。
  - 地区は44（カレンダーの「対象地域」。名前は「青葉台1〜3丁目」「大岡山1・2丁目」の形）。同じ曜日の地域は1つの日程にまとめた（28日程）。
  - 地区の読み：郵便番号一覧の読みと27の町名をくらべ、ちがう「柿の木坂＝かきのきざか」「五本木＝ごほんぎ」「洗足＝せんぞく」「中町＝なかちょう」を `YOMI` に書いた。

## 品目

- 区の「資源・ごみの分別品目一覧（50音順：令和8年4月改訂）」PDF（Excel で作った表。文字あり）→ **933件**（表の行 779。`make_items.py`）。目黒区には品目のオープンデータがない。
  - 行は横の罫線で分ける。品名のセルが細かく分かれている品目（「いす」→「パイプ椅子」など）は「いす（パイプ椅子）」の名前にした。出し方の列が細かい行をまとめたセルのとき（蛍光管）は、その文をどの行にも付けた。
  - 種別：資源の列の文字（プラ・ペット・びん・缶）と、●の列（可燃・不燃・水銀・古紙・粗大・不可の■）をすべて区分にした（**区分が2つ以上の品目は、同じ品名を区分ごとに並べた**。例：茶碗＝資源（プラスチック）と不燃。材質で分かれる）。●がない行は※の列（「出し方と注意点」を見る）を区分にした。資源の品目は、注意の頭に「資源（プラスチック）」などと書いた。
  - 印がない行：ノートパソコン（出し方：メーカー・認定事業者へ）は「×」。ビーズクッションの中身（出し方：清掃事務所に問い合わせ）は区分が決められないので入れなかった。カッターの水銀の列の「.」は表のよごれとみてのぞいた。
  - 読みは品名から（かっこの中の説明・【】はのぞく。「IC（アイシー）」はかっこの読み）。pykakasi の読みちがい「傘立て」を直した。
- 区分の出し方（`city.js`）は、区のページ「燃やすごみの出し方」「燃やさないごみの出し方」「水銀を含む製品の出し方」「びん・缶・ペットボトル・プラスチックの出し方」「古紙の出し方」「区では収集できないもの」と、冊子をもとに短くまとめた。
