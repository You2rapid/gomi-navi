- 作り方（`calendar.py`）：
  - **地域別カレンダー PDF 24枚を全日読む**（`read_pdf`）。白い字（前の月・次の月のマス）はのぞく。月の見出し（「2026年 10 月 October」）の下の曜日の見出し（日〜土）で列を決め、日の数字の位置と数字で日付を決める。区分の文字は、すぐ上の日の数字に結びつける。4〜9月の版と10〜3月の版で見出しの位置が少しちがうので、曜日の見出しは「日月火水木金土」の7つのまとまりで探す。
  - PDF の上の曜日（例：資源 火曜日、プラスチック 水曜日、燃やすごみ 月曜日・木曜日、燃やさないごみ 1回目・3回目 土曜日）の決まりで1年分の日を作り、年末年始の表の「12月の最後」と「1月の最初」の間の日をのぞく。**それを PDF から読んだ日と全日くらべる**（合わなければ止まる）。4〜9月と10〜3月の版で曜日の決まりが同じことも確かめる。
  - 年末年始のお知らせがその年度のものでなければ（見出しの令和の年がちがう）、12/27〜1/3 を「未定」にする。
  - 地区は12（カレンダーの「対象地域」。名前は「両国、亀沢、石原、横網」「本所1〜2丁目、東駒形1〜2丁目、吾妻橋、向島1〜3丁目」の形）。地区の読みは、地区名の町の読みを「、」でつないだ（どの町のひらがなでも探せる）。郵便番号一覧の読みとちがう「吾妻橋＝あづまばし」「本所＝ほんじょ」「向島＝むこうじま」「立川＝たてかわ」など9つを `YOMI` に書いた。
