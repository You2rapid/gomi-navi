  - 区の「令和8年版ごみ・リサイクルカレンダー」（PDF、画像。2026年1〜12月）p.13〜15 の収集曜日一覧 … 見くらべ用。**HTML の表とすべての行が同じ**だった。カレンダーの日付のマスには、収集日の印はない。
  - 区のお知らせ「令和7年度 年末年始の資源・ごみ収集」（PDF、画像。全地域・八潮5丁目・大森駅前住宅の3枚）… 年末年始の形を見るため。
  - 収集日のオープンデータ「ごみ収集日」（t131091d0000000007）はファイルが 2017年のままなので使わない。
- **品川区の収集日は、町名・丁目ごとに曜日で決まる**。燃やすごみ 週2回（八潮5丁目・南大井6丁目18番（大森駅前住宅）は週3回）・資源（プラスチック・ペットボトル・びん・缶・古紙・乾電池など）週1回・陶器・ガラス・金属ごみ 月2回（第1・第3 か 第2・第4 の曜日）。
  **祝日も収集する**（令和7年度の年末年始のお知らせで、成人の日 2026/1/12 が「第2・4月曜」の年始の最初の日になっている）。
- 作り方（`calendar.py`）：
  - 7ページの表を読み、行ごとに曜日から1年分の日を作る。同じ曜日の組み合わせは1つの日程にまとめた（36）。
  - 地区は表の行を1つずつ（77）。名前は区のカレンダーの書き方（「荏原2〜4丁目」「大井1・2・4丁目」）。番地・号棟で分かれる行は「西大井1丁目（4番28号、…）」「西大井1丁目（4番28号、…以外）」のようにした（表の「上記以外」は、何以外かがわかる書き方にした）。
  - **年末年始**：令和8年度（2026年12月〜2027年1月）のお知らせは、まだ出ていない（2026-11-27。区のページは令和7年度のまま）。
    令和7年度は、ふだんの曜日とちがったのが 12/28〜1/4 の間だけだったので、**12/28〜1/4 を「未定」**にして日を入れない（`YEAR_END[2026]` の `tentative`。決まり A1）。
    お知らせが出たら、区分・曜日ごとの「12月終わりの収集日」「1月始めの収集日」を `YEAR_END[2026]["table"]`（八潮5丁目・大森駅前住宅は `"special"`）に書き写し、`tentative` を消して作り直す。
    書き写した表と作った日が合わなければ止まる。**令和7年度の表を書き写して試し、77地区すべてで表と合うことを確かめた**（そのときの書き方は `calendar.py` の説明のとおり）。
  - 地区の読みは、郵便番号一覧の読みとちがう7の町を `YOMI` に書いた（荏原＝えばら、小山＝こやま、戸越＝とごし、中延＝なかのぶ など）。
- 置き場所：`元データ/13_東京都/13109_品川区/2026年度/`（`収集日.html`・`曜日/1003964〜1003970.html`・`カレンダー.html`・`カレンダー.pdf`・`年末年始/`）、`分別の冊子/`（カレンダー）、`オープンデータ/`

  - 「収集できません」のうち、エアコン・テレビ・冷蔵庫・洗濯機・衣類乾燥機は「家電」。
