## 収集日

- 使った資料
  - 区のサイト「ごみと資源 収集曜日検索」の CSV https://www.city.suginami.tokyo.jp/documents/12125/garbage.csv
    … 52地区（町丁目）ごとの可燃ごみ・不燃ごみ・びん かん プラ・古紙 ペットボトルの曜日と、地域のカレンダー PDF の URL。
  - 地域ごとの「ごみ・資源の収集カレンダー」（令和8年度、PDF 28枚） https://www.city.suginami.tokyo.jp/shared/garbage/<番号>.pdf
    … A4 3ページ。2・3ページに6か月ずつ。日付のマスに「可燃」「不燃」「びん かん プラ」「古紙 ペット」の文字。
- **杉並区の収集日は、町丁目ごとに曜日で決まる**。可燃ごみ 週2回・不燃ごみ 月2回（第1・3か第2・4の曜日）・びん かん 資源プラスチック 週1回（同じ曜日）・古紙 ペットボトル 週1回（同じ曜日）。**日曜日と年末年始（12月31日〜1月3日）をのぞき、祝日も収集する**。
- 作り方（`calendar.py`）：
  - CSV の行を、そのまま地区にする（52地区・26日程）。
  - **28枚のカレンダー PDF のマスの文字を読んで、曜日から作った日と1年分すべて1日ずつくらべる**（合わなければ止まる）。年末年始の休み（12/31〜1/3 のマスが空いている）も PDF で確かめた。
  - 地区の読みは pykakasi で作り、上高井戸（かみたかいど）・堀ノ内（ほりのうち）だけ手で書いた（`YOMI`）。52地区すべて郵便番号一覧の読みと合っている。
- 置き場所：`元データ/13_東京都/13115_杉並区/2026年度/`（`garbage.csv`・`カレンダー/<番号>.pdf`・`刊行物.html`）
- **毎年やること**：
  - 4月ごろ：新しい年度のカレンダー PDF が出たら `download_sources.py` → `update_year.py`。年末年始が 12/31〜1/3 でなければ `calendar.py` の `YEAR_END` に書く。
  ```
  python gomiappV3.1/tools/download_sources.py 2027 13115
  python gomiappV3.1/tools/update_year.py 2027 13115
  ```

## 品目

- 区の「ごみと資源の分け方・出し方『50音順』」（PDF、31ページ、令和8年4月からの修正版） https://www.city.suginami.tokyo.jp/documents/713/goju.pdf
  → `元データ/13_東京都/13115_杉並区/分別の冊子/goju.pdf`。**画像だけの PDF（文字がない）**なので、Windows の文字読み取り（OCR、`ocr.ps1`。光市と同じもの）で読んだ。読んだ結果は `分別の冊子/goju_ocr/`。
- **861件**（`make_items.py`）。
  - 表の罫線（黒い横線）で行を、決まった位置で列（品名・用途 素材 形状・分別・出し方と注意点）を分ける。品名は「品名（用途 素材 形状）」にした。
  - 区分のマス・用途のマスが OCR で空になった行は、マスだけを切り出して読みなおした（`goju_ocr/cells/`）。それでも読めなかった区分17・品名37は、画像を見て `make_items.py` の `CATFIX`・`NAME` に書いた。
  - OCR の読みまちがい（「/ヾ」→「バ」、「)レ」→「ル」、「工アコン」→「エアコン」、「ポトル」→「ボトル」など）は `FIX`、注意の文の電話番号・URL は `NOTEFIX` で直した（パソコン・ボタン電池・充電式電池の電話番号と URL は画像と見くらべた）。
  - 「不燃または粗大」のように区分が2つあるときは、はじめの区分にして、注意に「（不燃ごみ・粗大ごみ）」と書いた。「拠点回収、不燃または粗大」（小型家電など）は、集積所に出せる「不燃」にした。
  - 区分：可燃・不燃・資源プラ・びん・かん・古紙・ペットボトル・粗大・拠点回収・収集不可（「家電リサイクル法」とあるものは家電）。資源プラ・びん・かんは「びん・かん・プラ」の日、古紙・ペットボトルは「古紙・ペット」の日に出す（`city.js` の `dayAs`）。
- 冊子『ごみと資源の分け方・出し方』（令和8年度版、文字あり）の10ページ「分別に迷うもの」とくらべた：同じ名前があった100品目のうち89は区分が同じ。のこり11は、50音順で「可燃または粗大」「資源プラまたは可燃」のように2つ書かれていて、冊子ではもう一方を書いているもの（ヘルメット・ポリタンク・バインダー（プラスチック製）など）か、名前の分け方がちがうもの（ハンガー）で、食いちがいではなかった（バインダー・ビデオデッキは画像でも見た）。
- 品目のオープンデータ「ごみの分別方法一覧」（a2.csv、CC BY 4.0、令和7年4月時点、128品目）は、令和8年度の表より古く（スポンジ・ハンガーなどの区分が変わった）品目も少ないので使っていない（`元データ/…/オープンデータ/a2.csv` に置いた）。
