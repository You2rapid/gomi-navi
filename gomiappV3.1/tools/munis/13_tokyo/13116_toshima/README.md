- 作り方（`calendar.py`）：
  - 曜日一覧の画像を 200dpi に拡大して見て、58行を `TABLE` に書き写した（町丁名は区の書き方のまま。全角の数字・記号は半角に）。
  - **年末年始の一覧（文字の PDF）を読み、書き写した表から作った「12月の最後の日・1月の最初の日」（区分ごとに4つずつ）と全行くらべる**（合わなければ止まる）。年末年始の一覧の町丁名は、曜日一覧とすこし書き方がちがう行（「34番（14〜20号）」）と、3つの行を1行にまとめた行（東池袋2丁目…・東池袋3丁目…・東池袋4・5丁目）があるので、`ALIAS` に書いた。「池袋1・4丁目、2丁目14番5号…」のように2つの行が1行のものは、プログラムで見分ける。
  - 年末年始の休みは、お知らせのページの文から読む（書いてある曜日がその年の日付と合うかも確かめる）。その年度のお知らせ（10月ごろ）がまだなければ、12/31〜1/3 を「未定」にする。

  - 地区の読み：郵便番号一覧の読みと町名をくらべ、ちがう「上池袋＝かみいけぶくろ」「雑司が谷＝ぞうしがや」を `YOMI` に書いた。

## 品目

- 冊子の「50音順分別一覧表」（PDF 2ページ、p.30〜33）→ **251件**（`make_items.py`）。
  - この PDF は**文字が図形**（文字として読めない）。分別区分のマス（色の四角）を1行とみて、**区分は色で**決める（燃やす＝赤・金陶ガ＝青・紙布＝緑・プラ＝水色・びかペ＝黄緑・不可＝白）。「粗大」「区施設等」「家電・パソコン」は同じ黄色のことがあるので、マスの文字を OCR で読んで見分ける。
  - 品名と注意は、マスの左右を 400dpi の画像にして **Windows の OCR**（`ocr.ps1`。杉並区と同じもの）で読んだ。読めなかった品名（25）・区分の字（3）は画像を見て `NAME`・`CATTEXT` に、読みまちがいは `FIX`・`NOTEFIX` に書いた。同じ四角が2つ重なっている行（白い四角の上に色の四角）は、色のあるほうを使う。
  - 区分：燃やすごみ・金属・陶器・ガラスごみ・段ボール・紙・布類・プラスチック・びん・かん・ペットボトル・粗大ごみ・区施設等（→「拠点」。注意の頭に「区施設等の回収ボックスへ」）・家電・パソコン（→「家電」）・不可（→「×」）。
  - 作り直すとき：`python gomiappV3.1/tools/munis/13_tokyo/13116_toshima/make_items.py`（OCR からやり直すときは `--ocr`。番号は PDF のマスの順なので、新しい冊子では `NAME` などを見直す）。
- 区分の出し方（`city.js`）は、区のページ「資源の分け方、出し方」「燃やすごみ・金属・陶器・ガラスごみ」「粗大ごみの出し方」と冊子をもとに短くまとめた。
