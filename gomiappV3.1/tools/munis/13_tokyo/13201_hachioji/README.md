- 作り方（`calendar.py`）：
  - PDF の文字の位置で、区分の名前を日付のマスに結びつける。可燃・不燃の袋の絵の中の「可燃ごみ 専用」と、お知らせの囲みの大きい字は数えない（区分の文字は 10.5pt より小さい）。「容器包装／プラスチック」と2行に分かれたマス、「有害ごみ（小型充電式電池等）」が1行につながったマスがある。
  - 月の終わりの「23/30」「24/31」のマス（斜めの線で2つの日を分けたマス）は、マスの左上を基準に区分を集め、同じ区分の文字が2つなら両方の日、1つならその区分の前の2回の間かくから、どちらの日かを決める（毎週の区分で文字が1つなら止まる）。令和8年度は8月24日/31日（月）だけが区分のあるマスだった。
  - 確かめ：12か月そろっているか・日付の数字が1日〜月末まであるか・「びん」と「有害ごみ」がいつも同じ日か・町名一覧と収集地区一覧（と書き方のちがい）が合っているか。合わなければ止まる。

  - 地区の読みは、郵便番号一覧の読みとちがう50の町を `YOMI` に書いた（○○町＝まち／ちょう、兵衛＝ひょうえ、廿里町＝とどりまち など）。138地区すべて郵便番号一覧の読みと合っている。
