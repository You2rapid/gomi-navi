## 収集日

- 使った資料
  - **オープンデータ**：東京都オープンデータカタログサイトの大田区「資源・ごみ収集曜日、清掃事業所管轄一覧」（xlsx、CC BY） https://catalog.data.metro.tokyo.lg.jp/dataset/t131113d0000000024
    → `元データ/13_東京都/13111_大田区/オープンデータ/資源・ごみ収集曜日、清掃事業所管轄一覧.xlsx`。シート名は「R07全域」（令和7年度）。空のセルは上の行と同じ（結合セル）
  - 区のサイト「年末年始の資源とごみ収集のお知らせ」（令和8年度、2026-11-09 更新） https://www.city.ota.tokyo.jp/oshirase/mokutekibetsu/gomi/nennmatunennsi.html
    … 住所（町丁目）別の年末最終日・年始開始日の表（88行。結合セルあり）
  - 区のサイト「資源とごみの収集日」（2026-03-30 更新） https://www.city.ota.tokyo.jp/seikatsu/gomi/shigentogomi/gomishigen.html
    … 不燃ごみの地区別収集日一覧（令和8年4月〜9年3月、12グループ）と、「収集曜日」PDF（令和8年度の町丁目別の表。結合セルが多く、文字の順がばらばらなので読み取りには使わず、目で確かめるのに使った）
  - 見くらべ用：「令和8年度 プラ・資源・ごみ収集曜日一覧」（大森・調布・蒲田の清掃事務所ごと、PDF。不燃ごみの日付入り）
- **大田区の収集日は、町丁目（番地で分かれるところもある）ごとに曜日で決まる**。プラスチック 週1回・資源（7品目）週1回・可燃ごみ 週2回・不燃ごみ 月2回（その月の1・3回目か2・4回目の曜日。29〜31日は収集なし）。**祝日も収集する**。年末年始だけ休み（令和8年度：12月31日〜1月3日）。
- 作り方（`calendar.py`）：
  - 地区は、年末年始の表の行（その年度の分け方）。曜日は、オープンデータの同じ町丁目の行（書き方のちがい「、／・」「から／〜」「全域 (1丁目、2丁目)／全域」「18番、19番／18・19番」をそろえてくらべる）。
  - **年末年始の表の8つの日（4区分の年末最終日・年始開始日）が、曜日で作った日と合うか、88地区すべてで確かめる**（合わなければ止まる）。オープンデータは令和7年度のシートだが、令和8年度もすべて合った。
  - 不燃ごみの日付の表（12グループ × 24日）とも見くらべて、すべて合った。
  - 令和8年度は、**大森北5丁目が番地で2つに分かれていて**、オープンデータにない。区の「収集曜日」PDF（令和8年度）で、2行とも「1丁目・4丁目・5丁目」と同じ曜日（プラ 月・資源 木・可燃 火金・不燃 2・4水）なのを見て、`SAME_AS` に書いた。
  - 地区の説明は、オープンデータの管轄の清掃事務所（大森・調布・蒲田 → 区のページの書き方「大森清掃事務所」「蒲田清掃事務所（調布地区）」「蒲田清掃事務所（蒲田地区）」）。
- 置き場所：`元データ/13_東京都/13111_大田区/2026年度/`（`資源とごみの収集日.html`・`年末年始のお知らせ.html`・`収集曜日.pdf`・`08funennoomori.pdf` など）
- **毎年やること**：
  - 4月ごろ：「資源とごみの収集日」の不燃ごみの表が新しい年度になる。オープンデータの曜日一覧が新しい年度になっていれば取り直す（なっていなければ、区の「収集曜日」PDF と年末年始の表で分け方のちがいを見て `SAME_AS` に足す）。
  - 11月ごろ：「年末年始の資源とごみ収集のお知らせ」が出たら、`YEAR_END` に休みを足し、`download_sources.py` → `update_year.py`（年末年始の表がないと作れない。前の年度の表のままだと、年末年始の日が合わずに止まる）。
  ```
  python gomiappV3.1/tools/download_sources.py 2027 13111
  python gomiappV3.1/tools/update_year.py 2027 13111
  ```

## 品目

- **大田区の分別辞典は、民間の「ごみサク」**（https://www.gomisaku.jp/0056/）。ごみサクの利用規約は許可なく複写・転用等を禁じているので、**写さずに、出し方タブと画面の下からリンクだけ**（京都府の亀岡市・長岡京市と同じ）。品目のオープンデータもない。
- そこで、区のページにのっている品目だけを使った（決まり A1）：**108件**（`make_items.py`）
  - 「プラスチック」のページの「主な分別リスト」の表（42。品目・分別区分・出し方のポイント）
  - 「可燃ごみ」「不燃ごみ」「資源（7品目）」「区では収集できないもの」「粗大ごみ」のページの例（66。`PAGE_ITEMS` に書き写した）
- 注意：**スプレー缶・カセットボンベは、使い切って別の袋に入れて「資源」の日**（不燃ごみのページ）。

## 今いる場所から探す

- e-Stat の町丁（221）を、地区名の町名と「○丁目」でくらべる（`geo.py`。練馬区と同じ形）。全域の地区は、その町のすべての町丁。番地で分かれているところは、同じ丁目に候補が2つ以上（12町丁）。
