- **江東区の収集日は、地区ごとに曜日で決まる**。資源（びん・缶・ペットボトル・古紙・発泡トレイ）週1回・プラスチック 週1回・燃やすごみ 週2回・燃やさないごみ 隔週。**祝日も収集する**（収集日一覧の赤い日付も収集）。
- 作り方（`calendar.py`）：
  - 収集日一覧の PDF は画像なので、地区ごとの町名・曜日・燃やさないごみの4月の1回目の日を `DISTRICTS[2026]` に書き写した。燃やさないごみはその日から2週ごと。
    **12地区すべての画像で、燃やさないごみの4月〜3月の日付が2週ごとの日と合っていた**（年末年始に当たる日は一覧にのっていない）。
  - 年末年始（`YEAR_END[2026]`）：12月31日〜1月3日は休み。燃やさないごみの臨時の収集日：4地区 12/24・1/7、5地区 12/25・1/8、6地区 12/26・1/9（ふだんの 12/31・1/1・1/2 の代わり。アプリでは「振替」と出る）。2地区 12/29・3地区 12/30 も「臨時」と書いてあるが、ふだんの2週ごとの日と同じ。
    **12地区すべての年末年始カレンダー（12/13〜1/9）の画像と、作った日が合っていた**。
  - オープンデータの58町の曜日と、`DISTRICTS` の曜日をくらべる（合わなければ止まる）。**オープンデータは豊洲がぜんぶ6地区、塩浜1丁目が6地区のまま**で、令和8年度の一覧（豊洲1・3丁目と塩浜は12地区、豊洲2・4〜6丁目は6地区）とちがうので、地区は令和8年度の一覧を使った（`ODIFF`）。
  - 地区は、収集日一覧の町名（「東砂6〜8丁目」「豊洲1・3丁目」など）を1つずつ地区にした（58）。日程は地区番号で、アプリでは「6地区」と出し、地区番号からもえらべる。
  - 地区の読みは、郵便番号一覧の読みとちがう9の町を `YOMI` に書いた（青海＝あおみ、千田＝せんだ、冬木＝ふゆき、新大橋＝しんおおはし など）。オープンデータの読み（「新大橋＝しんきば」「毛利＝もりした」など）はまちがいがあるので使わない。
- 置き場所：`元データ/13_東京都/13108_江東区/2026年度/`（`収集日一覧.html`・`収集日一覧.pdf`・`収集日一覧裏面.pdf`・`年末年始.html`・`年末年始/`）、`オープンデータ/`
- **毎年やること**：
  - **3月ごろ**：新しい年度の収集日一覧（PDF）が出たら、`download_sources.py` で保存し、画像を見て `DISTRICTS[<年度>]` を書き写す（町名・曜日・燃やさないごみの4月の1回目）。`update_year.py` でオープンデータの曜日とくらべる。
  - **11月ごろ**：年末年始のお知らせが出たら、地区別カレンダーを見て `YEAR_END[<年度>]` を書く（休み・臨時の日）。書くまでは年末年始は「未定」と出る。
  ```
  python gomiappV3.1/tools/download_sources.py 2027 13108
  python gomiappV3.1/tools/update_year.py 2027 13108
  ```
