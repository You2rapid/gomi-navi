## 収集日

  - 収集日のオープンデータはない（東京都オープンデータカタログにある葛飾区のごみのデータは「ゴミの分別方法一覧」だけ）。
- **葛飾区の収集日は、16の収集地区ごとに曜日で決まる**。プラスチック製容器包装（プラマークの日）週1回・資源（製品プラスチック・ペットボトル・食品トレイ・びん・缶・古紙）週1回・燃やすごみ 週2回・燃やさないごみ 月2回（第1・第3 か 第2・第4 の曜日）。**祝日も収集する**。年末年始は休み。
- 作り方（`calendar.py`）：
  - 簡易版 PDF の日の数字（文字）の位置から、月の見出しの下の**何行目・何列目か**で日付を決める。
  - マスの中の絵を、4倍の画像にして**色で**読む：緑の星＝資源、赤い玉＝燃やすごみ、青い三角＝燃やさないごみ、水色の四角＝プラマーク（日の数字はのぞく。祝日の赤い数字を数えないため）。
    絵は1つ 270 ピクセル以上、となりの絵のはみ出しなどは 41 ピクセルまでだったので、100 以上を「絵がある」にした（`MIN_PIXELS`）。
  - 地区ごとに区分の曜日（燃やさないごみは「第何○曜日」）を数えて決まりを作り、**決まりからはずれた日があれば止まる**。年末年始（12/29〜1/4）に休みになる日だけは、はずれてよい。2026年度は、はずれた日は年末年始の39日だけだった（12/31〜1/3 の休み。12地区は 12/30 も休み）。
  - **区の PDF の書きまちがい**（`MISPRINT`）：10地区の6月の最後の行が「30・31」（マスの位置は 6/29 月・6/30 火）。4地区の5月の最後の土曜日が「31」（位置は 5/30）で、5/31（日）のマスがない（日曜は収集がないので問題ない）。日付はマスの位置で決めるので、そのまま正しく読める。区への問い合わせ文にも書いた。
  - 地区は、区のページの町名・丁目の行を1つずつ地区にした（44）。簡易版の見出しの町名と見くらべる（合わなければ止まる）。アプリでは「収集地区4」と出し、収集地区の番号からもえらべる。
  - 地区の読みは、郵便番号一覧の読みとちがう9の町を `YOMI` に書いた（お花茶屋＝おはなぢゃや、金町＝かなまち、白鳥＝しらとり、新宿＝にいじゅく、四つ木＝よつぎ など）。
- 置き場所：`元データ/13_東京都/13122_葛飾区/2026年度/`（`収集カレンダー.html`・`簡易版/1〜16.pdf`・`カレンダー/1〜16.pdf`）、`分別の冊子/`（全地区共通ページ）、`オープンデータ/`
