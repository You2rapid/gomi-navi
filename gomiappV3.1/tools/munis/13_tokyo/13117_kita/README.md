- **北区の収集日は、町名・丁目（一部は番地・団地）ごとに曜日で決まる**。日付のカレンダーはない。
  可燃ごみ 週2回・不燃ごみ 月2回（第1・第3 か 第2・第4 の曜日。金属資源もこの日に別の袋で）・古紙・プラスチック 週1回（同じ日）・びん・缶・ペットボトル 週1回（資源回収ステーション）。
  **月〜土曜日に収集し、祝日も収集する。日曜日と年末年始（12/31〜1/3）は休み**。
- 作り方（`calendar.py`）：
  - 区のページの表を読み、行ごとに曜日から1年分の日を作る。同じ曜日の組み合わせは1つの日程にまとめた（65）。
  - 地区は表の行を1つずつ（136）。名前は「赤羽一丁目（1〜9番）」「赤羽一丁目（1〜9番以外）」のように、区の表の町名と地区（「全域」の行は町名だけ）。「(1〜3番・10番)の一部」のかっこは、取ると意味がかわるので残した。
  - 地域（赤羽・王子・滝野川）は、表の上の見出し（○○地区）から。`city.js` の `regions`。
  - **3つの団地は、一部の区分の曜日が「集積所の表示板に記載」**（都市機構赤羽北二丁目団地の可燃ごみ、王子五丁目団地・豊島五丁目団地の可燃ごみ・不燃ごみ）。曜日が公表されていないので日を入れず、rules に「曜日は集積所の表示板で確かめてください」、地区の説明（`d`）にも同じことを書いた（決まり A1）。
    王子五丁目団地の古紙・プラスチックは「集団回収（古紙）・火曜日（プラスチック）」なので、火曜日を「古紙・プラ」の日にして、rules に「プラスチックだけ。古紙は集団回収」と書いた。
  - **年末年始**：お知らせのページの文（「可燃ごみの年末の収集作業については、12月30日（水曜日）まで曜日どおり…」）を読み、書いてある曜日がその年の日付と合うかも確かめる（合わなければ前の年度のお知らせとみて、12/31〜1/3 を「未定」にする）。
    令和8年度は、可燃・古紙・プラ・びん・缶・ペットボトルが 12/30 まで、不燃ごみが 12/28 まで、どれも 1/4 から。作った日が、すべての日程でお知らせと合うこと（と 12/31〜1/3 に日がないこと）を `calendar.py` が確かめる。
  - 区のページの表の見出しが7つの表で「ペットボト」（「ル」がない）になっている。区の書きまちがいとして、どちらも読めるようにした。
  - 地区の読みは、郵便番号一覧の読みとちがう9の町を `YOMI` に書いた（豊島＝としま、上十条＝かみじゅうじょう、栄町＝さかえちょう、岸町・昭和町＝○○まち、桐ケ丘＝きりがおか、西ケ原＝にしがはら など）。
