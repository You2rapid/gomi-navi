- 作り方（`calendar.py`）：
  - 地域ごとのページの表を読み、行ごとに曜日から1年分の日を作る。年末年始はお知らせのページの文（「○○○○年12月31日（○曜日）から○○○○年1月3日（○曜日）までお休みです」）を読み、書いてある曜日がその年の日付と合うかも確かめる（合わなければ前の年度のお知らせとみて、12/31〜1/3 を「未定」にする）。
  - **カレンダー PDF 25枚を全日読んで、作った日とくらべる**（合わなければ止まる）。月の見出し（「2026 年 4 月」）の下の曜日の列と週の行で、マスの文字を日付に結びつける。前の月・次の月のマスはのぞく。
    - PDF には**白い字で見えない文字**がある（江古田1・3丁目の木曜日の「資源プラ」など。マスに色の四角がない）。**色の四角の上にある文字だけ**を数える（`COLOR`）。1つの図形に四角がいくつも入っていることがあるので、四角を1つずつ取り出す。
    - マスの中にぽつんとある数字（上高田1丁目の12月の「1」）は、週の行とみなさない。
    - 「び缶ぺ」（ひらがなの「ぺ」）、「プラ」（「資源プラ」の短い書き方）もある。R8R9-20 だけ A4（ほかは A3）なので、位置の目安はページの幅に合わせる。
    - **区の PDF の書きまちがい**（`MISPRINT`）：本町3丁目（R8R9-19）の 5/28・8/27 のマスが、色は陶器・ガラス・金属ごみの青で、文字が「資源プラ」。曜日の表（第2・第4木曜日）と色のとおり、陶器・ガラス・金属ごみの日にした。区への問い合わせ文にも書いた。
  - 1つの PDF を使う地区（例：新井1・2・4・5丁目と上高田2丁目）は、曜日が同じことと、PDF の見出しにその地区名があることを確かめる。同じ曜日の組み合わせ＝1つの日程（25。PDF の数と同じ）。
  - 地区は表の行を1つずつ（42）。名前は「新井1・2・4・5丁目」（丁目は数字に）、「全域」の町は町名だけ（江原町・上鷺宮・沼袋・南台）。
  - **中野2・3・5丁目は「毎日収集地域は除く」**（全域のページと PDF の見出しにだけ書いてある。範囲の説明は区のページにない）。地区の説明（`d`）に「毎日収集地域をのぞく（毎日収集地域は清掃事務所 03-3387-5353 へ）」と書いた。
  - 地区の読み：郵便番号一覧の読みと19の町名をくらべ、ちがう「江古田＝えごた」を `YOMI` に書いた（中野区の江古田は「えごた」）。
