- 読み方（`calendar.py`）：カレンダーの PDF は文字が入っているので、日付の数字と札の位置から読む。札は、同じ月の中で、すぐ上の日付の行のうち、横の位置がいちばん近い日付のもの。
  日付の曜日が列の曜日と合わなければ止まる。白い文字（月の終わりのあとの見えない数字や札）は読まない。
  1つのマスに札が4つ重なる日（篠町Ⅱの4/1など）は、いちばん下の札が日付から42ほど下になるので、48まで見る。
- 区分（札）：燃やすしかないごみ・埋立てるしかないごみ・乾電池・ライター・プラスチック・ペットボトル・空きカン・空きビン・スプレー缶・小型金属類・紙類・草・木類。
- 祝日もふだんどおり収集する（カレンダーのとおり）。
- **年末年始**：どのカレンダーも12月30日〜1月3日が空いている（12/28・12/29 は収集あり）。市のページに「年末年始の収集については、収集日程を変更する場合がありますので、市のホームページや広報誌にて改めてお知らせいたします」とあるので、
  カレンダーのとおり収集なしで作り、`yearEnd` の `tentative` を `True` にした（自動チェックの注意1）。市のお知らせが出たら `YEAR_END` に足す（変更がなければ `"add": {}` で足す）。
- 置き場所：`元データ/26_京都府/26206_亀岡市/2026年度/`（`ごみ出しカレンダー.html`・`カレンダー_<町>.pdf`・`町別収集日程.pdf`）

## 今いる場所から探す・町名で探す

- 地図：e-Stat 国勢調査（令和2年）町丁・字等別境界データ `地図/r2ka26206.kml`（275の町丁）

  - 地区名が町名のもの（旭町・大井町・東つつじケ丘…）は、e-Stat の町名がその町名で始まれば、その地区。
  - 亀岡地区（東部・中部・西部）は、ページの表の町名（三宅町・荒塚町・余部町…）で始まれば、その地区。
