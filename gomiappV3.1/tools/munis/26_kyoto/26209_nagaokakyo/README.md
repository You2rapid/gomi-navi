## 収集日

- 使った資料（市のサイト。**オープンデータはない**。5374.jp に長岡京市のデータはあるが、利用条件が書かれておらず、休みの期間が2022年度のままなので、見くらべにだけ使った）
  - 「長岡京市のごみの出し方」 https://www.city.nagaokakyo.lg.jp/0000011246.html （家庭ごみの収集地区の表が**文字**で入っている）
  - 「令和8年度ごみ減量のしおり」（同じページの PDF。**画像だけ**、11ページ）
  - 「令和8年4月以降のごみ収集日程」 https://www.city.nagaokakyo.lg.jp/0000014052.html の「分別収集の日程表」（PDF。画像。しおり4・5ページと同じ）
- 長岡京市の収集日は2つの決まりの組み合わせ：
  - **家庭ごみ（可燃）**：週2回。町ごとに月・木曜日か火・金曜日。祝日・振替休日も収集。
  - **資源物（分別）**：A類（空きカン・ペットボトル・スプレー缶・ガスボンベ・その他不燃物）とB類（空きビン・筒型乾電池・蛍光灯）を月2回ずつ。その他プラスチックは A類・B類どちらの日にも出せる（AB共通）。
    地域は8つ。分別収集日程表に、月ごとの日付が書いてある（ゴールデンウィーク・シルバーウィーク・年末年始の祝日は休み、9/22・9/23 の代わりに 9/29・9/30 など）。
- 読み方（`calendar.py`）：
  - 家庭ごみの曜日：`AREAS` に町ごとに書き、市のページの収集地区の表（文字）と合っているかを `check_burn` で調べる（64地区すべて合っていた）。
  - 分別収集日程表は画像なので、**日付を目で読んで `SORT_DAYS` に書き写した**。書き写しのまちがいを見つけるため、どの日付も曜日と「第1・3／第2・4週」が合うかを調べる（合わないのは、日程表で赤丸の 9/29・9/30 だけで、`MOVED` に書いた）。
  - 日程表の8つの行：A類が第1・3○曜日の行は、B類が第2・4○曜日（同じ曜日）。逆も同じ（`ROWS`）。
- 地区：分別収集日程表の地域の町名（64）。日程（家庭ごみの曜日×資源物の地域）は16。地区名で日程が分かるので、日程の名前は出さない（`schedHide`）。
- **市の資料で分からないもの**（推測で入れていない。決まり A1）：
  - 「南浦」「舞塚」は、家庭ごみの収集地区の表にない → 家庭ごみの日はカレンダーに出ない（地区の説明に「市の環境業務課へ」と書いた）。
  - 「浄土谷」「調子3丁目」は、分別収集日程表にない → 資源物の日はカレンダーに出ない。
  - 市のページに「一部上記収集パターンと異なる地域があります」とある。5374.jp のデータには、馬場六ノ坪・神足橋本・勝竜寺六ノ坪・今里向イ芝が月曜日、浄土谷が第1・3月曜日、など、しおりにない日がある。市の資料にないので入れていない（下の「人がやること」）。
- **年末年始**：家庭ごみの年末年始は「広報長岡京（12月号予定）やアプリ、ホームページでお知らせ」。今は 12/31〜1/3 を仮に休みにしている（`yearEnd.tentative`、自動チェックの注意）。資源物は日程表のとおり（1/1 は休み）。
- 置き場所：`元データ/26_京都府/26209_長岡京市/2026年度/`（`ごみの出し方.html`・`ごみ減量のしおり.pdf`・`分別収集の日程表.pdf`）
- **毎年やること**（新しいしおりは例年3月、広報紙3月号と同時に配布）：
  ```
  python gomiappV3.1/tools/download_sources.py 2027 26209
  ```
  そのあと、新しい日程表の日付を `calendar.py` の `SORT_DAYS`・`MOVED`・`SORT_YEAR` に書き写し、地域・家庭ごみの表が変わっていれば `AREAS` を直してから
  `python gomiappV3.1/tools/update_year.py 2027 26209`。

- 自動チェック：直す 0・注意 2（2026-11-25）。注意は「年末年始の休みが仮」「品目が少なめ」（上に理由）。
