# 京都府（26）県のメモ

県の係（エージェント）が、県で共通のことと、市町村ごとの進み具合を書くメモです。
次の係が続きから作れるように、わかったことはここに書きます（手順書 `gomiappV3.1/tools/AGENT.md` の「0. 県ごとの進め方」）。

- 県のフォルダ：`gomiappV3.1/tools/munis/26_kyoto/`、データ：`gomiappV3.1/data/26_kyoto/`
- 元データ：`元データ/26_京都府/`

## 次の係へ

- いまの進み具合（2026-11-25）：京都市・宇治市・亀岡市・長岡京市が「できた」。**次は表の上から、舞鶴市（26202）**。
- 地図（e-Stat の KML）は25市町村ぶんそろっている（`元データ/26_京都府/<コード>_<名前>/地図/r2ka<コード>.kml`）。
- `build_geo.py` は必ず `26` を付けて動かす。`update_year.py 2026 <コード>` も中で `build_geo.py` を県ごとに動かす。
- 気をつけること（宇治市でわかったこと）：
  - 年度のカレンダーで年末（12/28〜31）が空いていて「12月15日号の市政だよりで知らせる」形がある。空いていたら `yearEnd.tentative: True` にして、README の「人がやること」に「12月中旬に YEAR_END に足す」と書く。アプリの「お知らせ」に「収集がありません」と出てしまうので、市の発表が出たらすぐ直す。
  - 市のサイトのページより、分別辞典の PDF が古いことがある（宇治市のボタン型電池）。区分ごとのページの「更新日」を見て、新しいほうに合わせ、README に書く。
  - 5374.jp のデータは、亀岡市・長岡京市・舞鶴市・福知山市・城陽市などにある。地区の分け方や区分の色を見くらべるのに便利だが、利用条件が書かれておらず古いこともあるので、元にはしない。
  - 同じ京都府の係が2つ動いていたことがある（亀岡市を途中まで作って止まった kyoto-pref-2）。始める前に `git status` と `tools/munis/26_kyoto/` を見て、作りかけのものがあれば引きつぐ。
  - 地区の数が15より少ない市（宇治市は11）は、アプリに地区の検索欄が出ない。地区の説明（`d`）に大字・小字を書いておくと、えらぶときに分かる。
- アプリの確認：`.claude/launch.json` の「gomi-local」はポート 8765 に固定。ほかのセッションが同じフォルダで 8765 を動かしているときは、`http://127.0.0.1:8765/gomiappV3.1/index.html?date=2026-12-21` を開けば、同じファイルを見られる。
