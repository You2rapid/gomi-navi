# 京都府（26）県のメモ

県の係（エージェント）が、県で共通のことと、市町村ごとの進み具合を書くメモです。
次の係が続きから作れるように、わかったことはここに書きます（手順書 `gomiappV3.1/tools/AGENT.md` の「0. 県ごとの進め方」）。

- 県のフォルダ：`gomiappV3.1/tools/munis/26_kyoto/`、データ：`gomiappV3.1/data/26_kyoto/`
- 元データ：`元データ/26_京都府/`

## 県で共通のもの

| もの | 場所・メモ |

| 県のオープンデータカタログ | 京都府のオープンデータカタログサイトで、府と市町村が自治体標準オープンデータセットを出している。ただし出しているのは公共施設・AED・人口・避難場所・投票所などで、**ごみの収集日・ごみ分別のデータセットはない**（「京都府・府内市町村 オープンデータ利活用推進コミュニティ」https://www.pref.kyoto.jp/digital/opendata/community.html 、2026-11-25 に確かめた） |
