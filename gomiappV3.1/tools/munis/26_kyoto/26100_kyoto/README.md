## 収集日

京都市の収集日は、**町ごとに曜日で決まっていて、毎年のカレンダーはない**（町名別一覧表が変わったときだけ変わる）。
祝日も収集する。年末年始だけ休み。

- 燃やすごみ 週2回（例：月・木）／山間部は週1回のところもある
- 缶・びん・ペットボトル 週1回、プラスチック類 週1回（山間部は月2回のところもある）
- 小型金属・スプレー缶 月1回（第○水曜日）、雑がみ 月2回（第○・○火曜日か水曜日）

ダウンロード元：収集日マップ https://www.city.kyoto.lg.jp/kankyo/page/0000000509.html の「町名別一覧表（○○区）」PDF（11区）と
右京区の京北地域の「収集日」PDF。`download_sources.py` が `kita.pdf`〜`fushimi.pdf`・`keihoku.pdf` の名前で保存する
（ページのリンクは `/kankyo/page/cmsfiles/` だが、ファイルは `/kankyo/cmsfiles/` にあるので、calendar.py で直している）。

### 毎年やること

1. **年末年始の日程**：市が10〜11月ごろに「令和○年度年末年始の家庭ごみ収集の日程等について」を出す。
   `calendar.py` の `YEAR_END` に、休みの期間（`off`）と、その日だけ収集しない区分（`skip`）を足して、`update_year.py` で作り直す。
   まだ足していない年度は、12/31〜1/3 を休みとして作り、状況一覧に「年末年始が仮」と出る。
2. 4月：ほかの自治体と同じく `download_sources.py` → `update_year.py`。町名別一覧表は区ごとに不定期に更新される。

### 読み取りの注意

- 表の「〃」は、上の行と同じ町（または同じ頭の町名）。省かれた頭は、**郵便番号の町名**（`元データ/全国/郵便番号/県別/26_kyoto.json`、`tools/build_zip.py` で作る）と
  e-Stat の町名（`地図/r2ka261xx.kml`）と照らし合わせて決める。郵便番号の町名は市の正式な町名そのもの（e-Stat は「学区＋町名」）なので、いちばん頼りになる。
  - どちらにも無い町名は、郵便番号の町名に合う頭をさがす（例：上賀茂の下の「〃 上御霊上江町」は上御霊上江町、西京区「北福西町 一丁目」は大枝北福西町一丁目）。
  - 郵便番号の町名と1文字だけちがう町名は、郵便番号の書き方に直す（`calendar.py` の `PAIRS`：圓→円、花背→花脊 などの異体字と、突技→突抜、管大臣→菅大臣 などの一覧表の誤字）。終わりの「町」のあるなしも直す。
  - それでも郵便番号の町名に無い町（山の中の字など）は、読み取りの注意.txt に「郵便番号の町名に見つからない」と出る。
  決まらないものは `calendar.py` の `PREFIX_FIX` に手で書く。
- 「〃〃」は頭を2つ省いたもの（例：「〃 石原上川原町」の下の「〃〃 京道町」→ 吉祥院石原京道町）。2つめの頭も e-Stat の町名と照らし合わせて決める。
- 「〃 二丁目」は、すぐ上の「…一丁目」の町の続き。頭をつけた町名が e-Stat に無いときは、上の町や前のまとまりの頭でためす
  （例：西京区の「北福西町 一丁目」は「大枝」を省いているので、その下の「〃 沓掛町」は大枝沓掛町）。
- 備考（「新千本通西側」など）は、町の行の高さを真ん中にして上下に何行も書かれている。すき間なく続く備考の行をまとめて、いちばん近い町に付ける。
- 読みだけが次の行にある町、読みが2行にわたる町、「（右京の里）」のように名前にかっこがある町にも対応している。
- 読み取りで気になったところは `元データ/26_京都府/26100_京都市/<年度>年度/読み取りの注意.txt` に出る（読めない行の町は、アプリに入っていない）。
- 同じ区に同じ名前で収集日がちがう町は、「（1）」「（2）」を付けている（市の一覧表で確かめてもらう）。

## 品目

京都市には品目のオープンデータがなく、市の「京都こごみネット」の分別検索もダウンロードできない。

1. **冊子**「新 正しい資源物とごみの分け方・出し方」（令和8年3月、`元データ/26_京都府/26100_京都市/2026年度/kiirosasshiR803.pdf`）の
   26〜34ページ「ごみ分別大辞典」。PDF は画像だけなので、画像を見て `booklet_r8.txt` に書き写した（530品目、1行に「品目|区分の記号|出し方のポイント」）。
   区分が2つ以上ある品目は、最初の区分をアプリの区分にして、注意の頭に「区分：○○／○○。」と並べる（「店頭」だけはほかの区分を優先）。
   冊子の略語（小金・拠回・缶等・リ法）とページ番号は、`make_items.py` の `WORDS` でアプリの言い方に直す。
2. `make_items.py` の `ITEMS`：市のホームページの区分ごとのページに書かれている品目。冊子と同じ名前のものは冊子を使う。

あわせて約600件。冊子が新しくなったら（毎年3月ごろ）、`booklet_r8.txt` を新しい冊子と見くらべて直す。
`python gomiappV3.1/tools/munis/26_kyoto/26100_kyoto/make_items.py`

## 区分の説明と出し方

`data/26_kyoto/26100_kyoto/city.js` に、市のページの決まりを自分のことばでまとめて書いている。区分ごとに市の公式ページへのリンクを付けている。

## 今いる場所から探す

`geo.py`：e-Stat の町名は「学区＋町名」（例：出雲路出雲路立テ本町）なので、町名別一覧表の町名が e-Stat の町名の終わりと合うものを候補にする。
京北地域は旧村の名前（黒田・宇津・山国・細野／周山・弓削）で地区を決める。合わない町丁（山の中の字など）は、区の一覧から選んでもらう。
地図は区ごとの KML（`地図/r2ka26101.kml`〜`r2ka26111.kml`）。e-Stat の境界データで区ごとに保存して、名前をそろえる。
